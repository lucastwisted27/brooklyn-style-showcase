# Brooklyn House Showcase

Crie uma landing page profissional, moderna e premium para a Brooklyn House Barbearia, localizada em Manaus/AM.

IMPORTANTE:

Esta página é uma DEMONSTRAÇÃO para apresentar ao proprietário da barbearia.

Não invente preços, serviços específicos, nomes de barbeiros, promoções ou informações que não foram fornecidas.

Use textos comerciais genéricos e editáveis quando uma informação específica não estiver disponível.

Não copie o site ou identidade visual de outras barbearias.

O objetivo principal é fazer o cliente entrar em contato pelo WhatsApp e conhecer a barbearia.

Identidade visual

Criar uma estética masculina, sofisticada e urbana, inspirada em barbearias premium modernas.

Paleta:

Preto como cor principal

Branco/off-white para textos

Dourado ou bronze como cor de destaque

Cinza escuro para elementos secundários

Visual:

Elegante

Premium

Masculino

Moderno

Alto contraste

Tipografia forte e sofisticada

Microanimações discretas

Muito espaço visual

Aparência de site profissional feito por uma agência

Evitar aparência de template genérico.

HERO

Criar uma primeira seção impactante com uma imagem grande de uma barbearia masculina premium.

Título:

"Seu estilo. Sua identidade."

Subtítulo:

"Uma experiência de barbearia pensada para quem valoriza estilo, cuidado e qualidade em cada detalhe."

Botões:

"AGENDAR HORÁRIO"

"CONHECER A BARBEARIA"

O botão "AGENDAR HORÁRIO" deve levar para o WhatsApp.

Adicionar uma pequena indicação de localização:

"Tarumã — Manaus/AM"

SEÇÃO SOBRE

Título:

"Mais do que um corte."

Texto:

"Na Brooklyn House Barbearia, cada detalhe faz parte da experiência. Um ambiente pensado para quem busca cuidado, estilo e um atendimento de qualidade."

Criar uma composição visual com uma imagem de ambiente de barbearia premium.

SEÇÃO SERVIÇOS

Título:

"Cuide do seu estilo"

Sugestões de categorias:

Barba

Acabamento

Tratamentos

Não inventar preços.

Cada card deve ter botão "Agendar".

SEÇÃO EXPERIÊNCIA

Criar uma seção visual mostrando que a Brooklyn House não vende apenas um corte, mas uma experiência.

Título:

"Uma experiência feita para você"

Destacar:

Atendimento personalizado

Ambiente confortável

Profissionais especializados

Cuidado nos detalhes

Usar imagens grandes e elegantes.

GALERIA

Criar uma galeria moderna com imagens de referência de barbearia masculina premium.

IMPORTANTE:

Não usar fotos de outras empresas identificáveis.

Usar imagens genéricas/licenciadas ou placeholders elegantes.

A estrutura deve permitir substituir facilmente pelas fotos reais da Brooklyn House.

Criar layout estilo masonry/grid com efeito hover.

AVALIAÇÕES

Criar uma seção de prova social.

Mostrar:

"4,8 ⭐ no Google"

"41 avaliações"

Como esses dados são da ficha do Google Maps, deixar esses números fáceis de editar caso sejam alterados.

Adicionar 3 depoimentos fictícios apenas como PLACEHOLDERS e deixar claramente estruturados para serem substituídos por avaliações reais.
